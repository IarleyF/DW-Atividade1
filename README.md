## 📌 Descrição do Projeto

Este projeto consiste no desenvolvimento de um site turístico sobre Icapuí, no Ceará, com o objetivo de apresentar informações sobre pontos turísticos, praias e outros locais de interesse da região.

O site é composto por três páginas principais: uma página inicial com informações sobre os pontos turísticos, uma página com informações sobre o autor e uma página de contato contendo um formulário para interação com o usuário.

O projeto foi desenvolvido utilizando HTML e CSS, aplicando diferentes elementos de estruturação, formatação, imagens, links, mapas e formulários.

## 📁 Estrutura do Projeto

```text
/
├── index.html
├── about.html
├── contact.html
├── imagens/
└── ...
````

### Páginas

* **`index.html`** — Página principal, contendo informações sobre os pontos turísticos de Icapuí.
* **`about.html`** — Página com informações sobre o autor do projeto.
* **`contact.html`** — Página de contato contendo o formulário.
* **`imagens/`** — Diretório contendo as imagens utilizadas no site.

## ▶️ Como executar o projeto localmente

Por ser um projeto desenvolvido em HTML e CSS, não é necessário instalar dependências.

Basta baixar ou clonar o repositório e abrir o arquivo `index.html` em um navegador.

Também é possível utilizar uma extensão como o **Live Server** no Visual Studio Code para visualizar o projeto durante o desenvolvimento.
